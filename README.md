# portfolio

Personal portfolio built with Next.js 16 (App Router), React 19, Tailwind CSS v4 and shadcn/ui (new-york, zinc/violet theme).

## Requirements

- Node.js 24 LTS
- pnpm 12

## Scripts

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build
pnpm lint
```

Add shadcn/ui components with `pnpm dlx shadcn@latest add <component>`, then run `pnpm lint --fix`.
